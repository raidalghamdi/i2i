## Notification preferences
- `NotificationPreference` entity + `NotificationPreferences` table, UNIQUE index on
  `(UserId, CategoryKey)`. A missing row means the category is un-muted, so no backfill
  is needed for existing users.
- `NotificationCategories` holds the static bilingual category catalog.
- Mute enforcement lives inside `NotificationService.CreateAndPublishAsync`, so every
  existing and future trigger site inherits it without per-call-site changes.
